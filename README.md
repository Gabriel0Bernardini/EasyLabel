EasyLabel é uma ferramenta \textit{open source} desenvolvida para auxiliar e automatizar o processo de rotulagem de imagens no formato YOLO. A aplicação executa localmente, utilizando modelos de detecção de objetos previamente treinados para gerar anotações automáticas a partir de imagens e vídeos. Além disso, integra um \textit{pipeline} que inclui extração de \textit{frames}, inferência e uma etapa de validação manual, permitindo ao usuário revisar e corrigir os rótulos gerados. O objetivo da ferramenta é reduzir o esforço manual, aumentar a eficiência na criação de \textit{datasets} e facilitar o desenvolvimento de modelos de visão computacional.
