EasyLabel é uma ferramenta open source desenvolvida para auxiliar e automatizar o processo de rotulagem de imagens no formato YOLO. A aplicação executa localmente, utilizando modelos de detecção de objetos previamente treinados para gerar anotações automáticas a partir de imagens e vídeos. Além disso, integra um pipeline que inclui extração de frames, inferência e uma etapa de validação manual, permitindo ao usuário revisar e corrigir os rótulos gerados. O objetivo da ferramenta é reduzir o esforço manual, aumentar a eficiência na criação de datasets e facilitar o desenvolvimento de modelos de visão computacional.


Para utilizar a ferramenta basta instalar os requirements.txt e rodar o main.py
